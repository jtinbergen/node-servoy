# Agent instructions

All work in this repository must follow **TDD (Test-Driven Development)**:

1. Write a failing test first.
2. Verify it fails (red).
3. Write the minimal implementation to make it pass.
4. Verify it passes (green).
5. Refactor if needed, keeping tests green.

Tests must be human-readable: clear, descriptive test names and `describe`/`it` blocks that explain the behavior being verified, not the implementation.

Run tests with `npm test`. No behavior change is complete without a corresponding test.
